# 주식 수익 최대화 AI

주가 상승 가능성과 위험을 함께 예측하고, 백테스트·워크포워드·모의매매로 검증한 뒤 제한적으로 실거래에 연결하는 AI 프로젝트입니다.

> 이 프로젝트는 수익을 보장하지 않습니다. 목표는 수수료와 슬리피지를 반영한 뒤에도 장기적으로 양의 기대수익을 가질 가능성이 높은 시스템을 만드는 것입니다.

### 진행 관리 규칙

1. 모든 작업을 시작하기 전에 이 README의 진행 상태를 먼저 확인한다.
2. `✅ 완료` 단계는 검증 실패, 요구사항 변경 또는 사용자의 명시적 요청이 없으면 다시 진행하지 않는다.
3. 단계가 완료되면 상태, 완료일, 검증 결과와 관련 커밋을 함께 갱신한다.
4. 일부만 구현된 단계는 완료로 처리하지 않고 `🟨 진행 중`으로 표시한다.
5. 다음 작업은 가장 앞에 있는 미완료 단계부터 진행한다.
6. 복잡한 모델이 단순 기준 모델을 실질적으로 이기지 못하면 채택하지 않는다.

## 주식 수익 최대화 AI 고정 개발 원칙

주식 수익 최대화 AI는 단일 모델에 의존하지 않고, 통계 모델·머신러닝·딥러닝·강화학습을 단계적으로 검증하여 결합한다.

프로젝트의 최우선 목표는 매일 0.1% 수익을 보장하는 것이 아니라 다음 조건을 만족하는 것이다.

1. 수수료와 슬리피지를 반영한 후에도 양의 기대수익을 유지한다.
2. 특정 종목이나 특정 상승장에서만 작동하지 않는다.
3. 최대 낙폭과 일일 손실을 제한한다.
4. 단일 백테스트보다 워크포워드와 모의매매 결과를 우선한다.
5. 복잡한 모델이 단순 전략보다 우수하지 않으면 사용하지 않는다.
6. 실거래 전 충분한 모의매매와 장애 테스트를 수행한다.
7. 미래 데이터 누수와 과적합을 엄격하게 차단한다.

## 확장된 20단계 개발 계획

### 1. 프로젝트 구조와 실행 환경
설정, 로그, 테스트, 모델 버전, 데이터 버전을 관리할 수 있는 기반을 만든다.

### 2. 거래 목표와 위험 한도
시장, 시간봉, 보유 기간, 최대 보유 종목, 손절, 일일 손실과 최대 낙폭을 고정한다.

### 3. 데이터 수집
가격, 거래량, 시장지수, 변동성, 환율, 기업 정보, 공시와 뉴스 데이터를 수집한다.

### 4. 데이터 품질 관리
결측치, 중복, 이상치, 액면분할, 상장폐지 종목과 생존편향을 검사한다.

### 5. 특징 생성
기술적 지표, 모멘텀, 변동성, 거래량, 시장 상대강도와 추세 상태를 생성한다.

### 6. 단순 기준 모델
이동평균, 모멘텀, 평균회귀와 Logistic Regression을 기준선으로 사용한다.

### 7. 트리 기반 머신러닝
Random Forest, XGBoost, LightGBM과 CatBoost를 비교한다. 상승 확률, 예상 수익률, 예상 변동성, 손실 확률과 비거래 확률을 분리해 설계한다.

### 8. LSTM과 시계열 딥러닝
LSTM, GRU와 Temporal CNN에 수익률, 거래량 변화, 변동성, 시장지수, 섹터 흐름, 추세 상태와 기존 모델 예측값을 입력한다. 동일 테스트 구간에서 기준 모델보다 명확히 나을 때만 채택한다.

### 9. Transformer 기반 시계열 모델
Temporal Fusion Transformer와 PatchTST 등을 실험하되 데이터 부족이나 과적합이 확인되면 사용하지 않는다.

### 10. 시장 국면 탐지
상승장, 하락장, 횡보장과 고변동성장을 이동평균·변동성 규칙, Hidden Markov Model, 군집화와 분류 모델로 비교한다.

### 11. 앙상블 AI
트리 모델, LSTM, 변동성 모델, 뉴스 감성 모델과 국면 모델을 검증 성과 기반 가중치 또는 메타 모델로 결합한다.

### 12. 강화학습 환경 구축
현금, 포지션, 평균 매입가, 미실현 손익, 시장 특징, 예측 확률, 변동성과 거래 기록을 상태로 구성한다. 행동은 매수·매도·유지·비중 축소·비중 확대만 허용한다. 보상에는 순수익, 비용, 낙폭, 과다 거래, 변동성과 집중투자 패널티를 포함한다.

### 13. Offline Reinforcement Learning
과거 데이터와 모의매매 기록으로 Conservative Q-Learning, Implicit Q-Learning, Decision Transformer와 제한된 PPO를 검토한다. 수익률뿐 아니라 낙폭, 비용과 안정성도 개선해야 채택한다.

### 14. 워크포워드 검증
`학습 → 검증 → 테스트 → 시간 이동 → 재학습`을 반복하고 각 구간에서 모델과 하이퍼파라미터를 새로 검증한다.

### 15. 과적합 방지
미래 데이터 누수, 생존편향, 데이터 스누핑, 과도한 튜닝, 특정 종목·기간 의존, 비용 누락과 불가능한 장중 체결을 검사한다.

### 16. 스트레스 테스트
수수료 2배, 슬리피지 2~5배, 부분 체결, 데이터 지연, 서버 재시작, API 오류, 급락장, 거래정지와 유동성 감소 조건에서 재검증한다.

### 17. 위험관리 AI
예측 모델과 주문 모델을 분리하고 위험관리 엔진이 매수 신호를 거부할 수 있게 한다. 종목 비중, 일일·주간 손실, 연속 손실, 최대 낙폭, 변동성 기반 주문 크기, 비상 중지와 중복 주문 차단을 구현한다.

### 18. 모의매매
실시간 시장 데이터로 최소 8주 이상 운영한다. 실제 체결과 예측, 백테스트 차이, 주문 누락·중복, 장시간 안정성, 재학습과 손실 제한을 검증한다.

### 19. 챔피언-도전자 구조
현재 모델을 챔피언으로 유지하고 새 모델은 도전자로 운영한다. 순수익, 최대 낙폭, 샤프지수, 비용, 안정성과 국면별 성과를 충분한 기간 개선할 때만 교체한다.

### 20. 소액 실거래
모의매매 통과 후 최소 금액으로 시작한다. 강화학습은 초기에는 주문을 직접 결정하지 않고 기존 전략의 비중 조절과 보조 판단부터 수행한다.

## 모델 채택 기준

새 모델은 다음 조건을 모두 만족할 때만 실제 시스템에 포함한다.

- 테스트 구간에서 기준 전략보다 우수
- 워크포워드 결과가 안정적
- 수수료와 슬리피지 반영 후 수익
- 최대 낙폭이 허용 범위 이내
- 여러 시장 국면에서 작동
- 모의매매 결과가 백테스트와 크게 다르지 않음
- 오류 발생 시 안전하게 중단 가능

복잡한 AI가 단순 모델보다 성과가 낮으면 단순 모델을 사용한다.
